# USDTF dApp (TRON Demo)

This is a front-end dApp (decentralized application) for interacting with the **USDTF** smart contract on the **TRON Nile Testnet**. It allows users to:
- View their balance
- Transfer demo USDTF tokens
- Connect with TronLink wallet
- (Optionally) Mint test tokens
